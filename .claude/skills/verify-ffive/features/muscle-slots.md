# Muscle slots in the builder

A builder day can hold a slot that names only a muscle. `#builder.add-muscle` is a menu of muscles, tapped by label (`button "Chest"`). An empty slot reads `Choose an exercise` above its muscle; tapping it opens the picker titled `Choose <muscle>`. While any slot is empty, Start Mesocycle and Save as Template are disabled and the bottom bar says `Choose an exercise for every muscle, or autofill them from the menu.` The toolbar's `#builder.menu` holds `#menu.autofill` (fills every empty slot from the lifter's equipment in suggestion order, never repeating an exercise within a day), `#menu.clear-exercises` (empties every slot, keeps the muscles) and `#menu.reset` (confirmed by `#dialog.reset`, puts the draft back to how the screen opened). The rules are `MesoDraft.autofill` and `MesoDraft.clearExercises` in FFiveCore.

- **Journey.** `journeys/muscle-slots.steps` (on disk, from `ffive-verify reset-data`: it opens the builder from the Mesos empty state's `#mesos.plan`): a blank draft gets Chest, Chest, Back; Start is a no-op; one slot is picked by hand, Autofill fills the rest, Clear empties all three, Reset restores the blank day, and a Quads slot autofilled then starts a block with a Quads `DaySlot`.
